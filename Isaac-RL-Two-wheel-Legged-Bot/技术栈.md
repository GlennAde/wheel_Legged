# Flamingo 项目技术栈

> **一句话**：Flamingo 双轮腿机器人 = Isaac Sim 4.5 仿真 + Isaac Lab 2.3 强化学习框架 +
> lab.flamingo 任务包 + CO-RL/PPO 算法，训练产物经 ONNX 导出后部署到真机。

---

## 1. 架构总览

```
┌─ 部署层  ONNX Runtime（真机 50Hz 推理循环）
├─ 算法层  CO-RL / PPO（自实现 runner，rsl_rl 风格）
├─ 任务层  lab.flamingo（任务配置 · 奖励 · 观测 · USD 资产）
├─ 框架层  Isaac Lab 2.3（Manager-based RL 环境）
└─ 仿真层  Isaac Sim 4.5（Omniverse Kit + PhysX GPU + Vulkan）
```

依赖链（editable 安装）：`env_isaaclab(venv)` → `IsaacLab` → `lab.flamingo` → 训练脚本

---

## 2. 技术栈明细

### 仿真与渲染
| 项 | 值 | 说明 |
|---|---|---|
| 物理引擎 | PhysX 5（GPU 加速） | 1024 并行环境靠 GPU 物理 |
| 渲染 | Vulkan / RTX | GUI 用 RTX 视口；headless 用 EGL，无渲染开销 |
| 场景格式 | USD | 机器人资产为 .usd；USD 不进 git，需手动解压 |
| 控制频率 | 50Hz 控制 / 200Hz 物理 | dt=0.005 × decimation=4 |

### 框架与任务
| 项 | 值 | 说明 |
|---|---|---|
| RL 框架 | Isaac Lab 2.3.0 | 七大 Manager：Scene/Event/Action/Observation/Termination/Reward/Curriculum |
| 任务注册 | gymnasium + hydra | 任务 `Isaac-Velocity-Flat-Flamingo-v1-ppo`（另有 Play 变体） |
| 机器人 | Flamingo rev01_5_2 | 8 执行器：2 髋(位置) + 4 肩/腿(位置) + 2 轮(速度) |
| 观测/动作 | 93 维 / 8 维 | 策略观测 stacking 2 帧（历史时序信息） |
| 配置管理 | hydra-core | 环境/智能体配置由 `co_rl_cfg_entry_point` 统一注入 |

### 算法
| 项 | 值 |
|---|---|
| 算法 | PPO（`--algo ppo`；另有 srmppo、off-policy） |
| 网络 | 512/256/128 + ELU；Actor 93→8，Critic 95→1 |
| 超参 | lr 1e-3（adaptive）、num_steps_per_env=24、num_mini_batches=4、clip 0.2、gamma 0.99/lam 0.95 |
| 归一化 | `empirical_normalization=False`（导出模型为 Identity，真机喂原始观测） |

### 工具链
| 环节 | 工具/命令 | 产物 |
|---|---|---|
| 环境 | uv venv（Python 3.10）+ `setup_env.sh` | 可复现环境 |
| 训练 | `./run_train.sh`（headless，默认 1024 envs） | `logs/co_rl/.../model_*.pt`（每 100 迭代） |
| 可视化 | `HEADLESS=0` / `--video` / tensorboard | 窗口 / mp4 / 曲线 |
| 评估导出 | `./run_play.sh --load_run <run>` | `exported/policy.onnx` + `policy.pt` + `env.pdf` |
| 部署 | ONNX Runtime（真机 50Hz） | 推理；sim2sim 在 `sim2sim_onnx` 分支 |

### 语言与硬件
| 项 | 值 |
|---|---|
| Python | 3.10.12（uv 创建） |
| 关键包 | torch 2.7.0+cu128 · gymnasium 1.2 · hydra-core 1.3.5 · numpy 1.26.4 · tensorboard 2.21 · wandb 0.28 |
| 硬件 | RTX 4060 Laptop 8GB / 15GB RAM / 24 核（i9-12900HX） |
| 系统 | Ubuntu 22.04.5 · 驱动 580.173.02 · 47GB swap |

## 4. 已知技术债

| # | 债务 | 现状 | 建议 |
|---|---|---|---|
| 1 | 仓库按 IsaacLab 2.0 编写，当前 2.3 | 已打 3 处补丁（dump_pickle 本地实现、2 处 wrappers.co_rl 类型引用） | 升级 IsaacLab 前回归测试 |
